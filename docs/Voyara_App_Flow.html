🔄 Development Workflow
Step 1
👨‍💻 Developer
Start Dev Server
Open VS Code terminal in VoyVibeFresh/ and run npx expo start
Step 2
📱 Developer
Open Expo Go
Scan the QR code in terminal with Expo Go on iPhone. Same Wi-Fi required.
Step 3
🤖 Claude
Edit Source Files
Claude reads and writes .js files directly via Cowork file access. No terminal needed.
Step 4
🔁 Auto
Hot Reload
Expo Go auto-reloads when files change. Shake phone → Reload if stuck.
Step 5
👨‍💻 Developer
Review & Commit
git add -A && git commit -m "feat: …" && git push from VS Code terminal.
